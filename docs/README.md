# GitHub Pages — activation (une fois)

Le workflow `.github/workflows/github-pages.yml` est prêt.

## Étapes dans GitHub

1. Ouvrir https://github.com/rainuia340/station-blanche/settings/pages
2. **Build and deployment** → Source : **GitHub Actions**
3. Aller dans **Actions** → relancer le workflow **Deploy GitHub Pages**

## Lien court une fois activé

```bash
curl -fsSL https://rainuia340.github.io/station-blanche/i | sudo bash
```

## Lien court immédiat (sans Pages)

```bash
curl -fsSL https://tinyurl.com/2ba278lg | sudo bash
```
